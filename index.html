🌐 Servidores Web y Archivos de Internet

1. ¿Dónde se guardan las páginas web?

A veces decimos que una página web está guardada “en la nube”. Pero la nube no es magia. En realidad, las páginas web se guardan en ordenadores muy potentes llamados servidores web.

👩‍💻 Creamos una página web
⬆️ La subimos a Internet
🖥️ Se guarda en un servidor web
🌍 Otros usuarios pueden verla

2. ¿Qué es un servidor web?

Un servidor web es un ordenador muy potente, conectado a Internet, donde se guardan páginas web, imágenes, vídeos, documentos y otros archivos.

🖥️ Servidor web = ordenador que guarda páginas web y las envía cuando alguien las solicita.

3. ¿Qué ocurre cuando escribimos una dirección web?

Cuando escribimos una dirección como www.iesalguadaira.es en el navegador, el ordenador busca dónde está guardada esa página.

1️⃣ Escribimos una URL
2️⃣ El navegador busca el servidor
3️⃣ El servidor encuentra la página
4️⃣ La página llega a nuestro ordenador
⬇️
La URL es la dirección de una página web.

4. Google Drive y la nube

Cuando iniciamos sesión con nuestro correo, podemos usar servicios como Google Drive. Allí podemos guardar archivos, fotos, vídeos o documentos y organizarlos en carpetas.

Aunque parezca que están “en la nube”, esos archivos realmente están guardados en servidores conectados a Internet.

5. Propiedad intelectual en Internet

En Internet hay millones de archivos: fotos, dibujos, vídeos, documentos, tablas, páginas web, música, etc.

Pero esos archivos han sido creados por personas. Por eso, muchos tienen derechos de autor o copyright.

No todo lo que está en Internet se puede copiar y usar libremente.

6. ¿Qué podemos usar legalmente?

Algunos autores permiten que sus imágenes o archivos se puedan utilizar. Para ello, pueden publicarlos con licencias abiertas, como Creative Commons, o como dominio público.

✅ Pixabay
✅ Unsplash
✅ Pexels
✅ Google Imágenes con filtro de derechos de uso

Cuando usemos una imagen, conviene indicar de dónde la hemos descargado y quién es el autor, si aparece esa información.
